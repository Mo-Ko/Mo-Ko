# Mohsin Kokab

**Senior Backend & AI Engineer in Berlin, Germany.** I build backend systems for
regulated industries and production LLM infrastructure: ten-plus years on Java and
Spring Boot platforms, including regulatory and compliance systems used by DAX40
clients and monolith to Kubernetes migrations on AWS, and in recent years Python
services for LLM orchestration, RAG and agentic systems. The method matters as
much as the stack: I work spec-driven, with verification gates that define what
"passing" means before the work starts. The full argument, with sources, is in
[The leverage is upstream: agentic engineering in 2026](https://www.kokab.dev/blog/agentic-engineering-loop).

Full case studies, with the architecture decisions and the evidence behind every
number, are at **[kokab.dev](https://www.kokab.dev)**.
